# 升级到 v1.x.x版本必读

> 返回 [README](../../README.md)。

## 背景

由于 v0.x.x版本其中对于部分组件设计存在问题，所以 v1.x.x版本进行了升级，v1.x.x版本将不再对部分组件进行升级，请务必在升级之前阅读此文档。

## 改动点

- gorm 从"github.com/coderyw/gorm" 切换回官方包 “gorm.io/gorm”
- kafka 从"github.com/Shopify/sarama" 升级到 "github.com/confluentinc/confluent-kafka-go/v2"
- kafka 配置不再兼容老配置
- 自定义配置支持实时 nacos 更新
- 【BREAKING】Nacos NamespaceId 改由 NACOS_NAMESPACE_ID 环境变量指定，不再从 ENVIRON 推导；使用 Nacos 时（当前版本本地也一样）未注入该变量将直接报错失败
- 其他请阅读更新文档 CHANGELOG.md

## 注意事项

- 升级后 gorm 包请 全局替换包 github.com/coderyw/gorm 到 gorm.io/gorm
- 自定义配置请维护好读写竞争问题
- 所有依赖 ca-common-util 的服务在升级到本版本之前，必须先在部署 yaml/Helm/ConfigMap 中追加 NACOS_NAMESPACE_ID；建议先在配置侧灰度注入再升级框架版本，避免发布过程中无配置导致启动失败
