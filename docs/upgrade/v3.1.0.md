# v3.1.0：凭据引用组件（secret）

> 返回 [README](../../README.md)。

- 依赖面：`pmicro/config` 空白导入 `secret/provider/csms` 与 `secret/provider/awssm` 完成注册，所有依赖 pmicro 的服务都会编进华为云 SDK v3（`huaweicloud-sdk-go-v3`）与 AWS `secretsmanager`，二进制体积相应增大；华为 SDK 间接带入 `go.mongodb.org/mongo-driver`（其错误包用到 bson）。
- 版本被动抬升：华为 SDK 要求 `github.com/json-iterator/go` 的伪版本 `v1.1.13-0.20220915233716-71ac16282d12`，Go 按最小版本选择会把服务里的 json-iterator 抬到该版本；`secretsmanager` 要求 `aws-sdk-go-v2` 核心 v1.45.1，`config`、`credentials`、`s3` 等子模块不随之升级。服务自身若钉了这些依赖的旧版本，升级后以 `go mod tidy` 结果为准并回归相关功能。
- 只把秘密写成引用：库名、主机、端口等非秘密配置不要放进凭据。引用取出的字符串值会登记日志按值脱敏，账号类键名（`username` / `user` / `account` 等）除外。
- 普通配置项不能含 `csms://`、`awssm://` 子串：会被当成拼接在文字里的非法引用，启动期直接退出，热更新期只打 ERROR 并保留旧配置（表现为"改了配置没生效"）。
- 启动耗时：sidecar 就绪探测最多 10s、凭据解析最多 20s（单凭据名），未配 startupProbe 时贴近约 40s 的 liveness 红线。引用多个凭据名、调大 `SECRET_RETRY_DEADLINE_SECONDS` 的服务须配 startupProbe；无 istio 注入的 Pod（CronJob 等）请设 `STARTUP_PROXY_WAIT_SECONDS=0`，否则每次启动固定多等约 3s。
